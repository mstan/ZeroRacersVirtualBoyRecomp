# Game artwork

`boxart.tga` is a project thumbnail composed from unmodified Zero Racers title
and starting-grid captures. It is not official retail box art. The game logo,
artwork and screenshots belong to Nintendo; the project license does not
relicense them. The thumbnail changes no game rendering or ROM data.

The shared Virtual Boy theme, controller artwork, icons and fonts come from
the pinned recomp-ui dependency. Their notices are included in release ZIPs.

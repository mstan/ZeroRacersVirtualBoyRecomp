# Zero Racers Virtual Boy Recomp

Development project for the Zero Racers Switch Online cartridge, using
vbrecomp and the shared recomp-ui launcher. Provide your own ROM; neither ROM
bytes nor generated cartridge code are tracked here.

ROM: 1,048,576 bytes, CRC32 `71553796`, SHA-256
`47421cd82dfd414d042d2f7f9db51e657d414d4ddfa46887efb544029fa11ce7`.

Work is tracked in the central Beads database: `beads-vb.3.1` (game)
and `beads-vb.1.1` (framework). Parity validation is in progress.

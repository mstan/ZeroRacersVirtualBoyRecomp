# Coverage pass, 2026-10-18

Player version: **0.0.4**. The retail Japan/USA Switch Online image includes the
USA release (CRC32 `71553796`). No ROM is distributed.

The practice menu normally clamps its selection to A5. The initial repeated
menu routes therefore did not qualify as coverage of all 15 courses. The new
ROM-bound profile writes the verified course ID and selector into WRAM before
using the game's original confirmation and race loader. No practice patch is
installed in the player build.

- All 15 original table entries were loaded, confirmed and driven. Three
  checkpoints per course (45 total) agree across CPU, WRAM, SRAM, VRAM, VIP,
  devices, both raw eyes and audio; every case has zero fallback.
- Normal Time Trial is a separate, unmodified menu route, using stage ID 16.
- Fresh independent Beetle runs agree at confirmation, start and driving for
  the late C5 course and at machine selection, start and driving in Time Trial:
  six checkpoints, nine planes, zero fallback. A timed-out earlier Time Trial
  attempt was excluded; its cause was not established.
- This samples all courses and Time Trial, rather than claiming completed cups,
  every lap transition or every ending. No widescreen provider is available.

`tests/coverage/suite.json` contains all 16 cases. Reproduce with a development
build and a new output directory:

```powershell
.\tools\build.ps1 -Rom 'C:\Games\zero_racers.vb'
python vbrecomp/tools/run_assisted_suite.py --runtime build/vbrecomp/runtime/ZeroRacersVirtualBoyRecomp.exe --rom 'C:\Games\zero_racers.vb' --suite tests/coverage/suite.json --out validation/courses-new
```

The shared runner mutes unattended output while retaining audio emulation and
audits state bytes, execution counters and visible captures. Player audio stays
normal. Production builds omit TCP debugging and CPU recording.

Generated code is partitioned into six translation units; the partition-only
audit preserved every original function body and dispatch. Shared build and
debugger fixes belong to vbrecomp. The optional color package remains 0.2.1.
The [author's practice-selector reference](https://www.virtual-boy.com/games/zero-racers/downloads/)
helped locate the original table; that patch is not shipped.
